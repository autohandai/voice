# Changelog

All notable Autohand Voice changes are documented here.

## 0.1.0 - 2026-07-27

- Established the `Autohand Voice` product identity for macOS Apple Silicon.
- Added the `autohand-voice-mlx` distribution and `autohand-voice` CLI.
- Made the CoreML/Apple Neural Engine helper available as
  `autohand-voice-stt`.
- Preserved Qwen3-ASR as the optional `qwen3-asr` extra.
- Added canonical `AUTOHAND_VOICE_` environment variables with legacy upstream
  variables accepted as migration fallbacks.
- Added privacy, engineering, contribution, and Autohand composer integration
  contracts.
- Preserved upstream history, documentation, licensing, and attribution.

The changelog inherited from `0xbrando/dictate` is retained in
[docs/upstream-changelog.md](docs/upstream-changelog.md).
